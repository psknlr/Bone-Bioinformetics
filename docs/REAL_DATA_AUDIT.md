# Real-data audit

This project is designed to avoid simulated pharmacology, expression, GWAS, or network evidence.

## What is computed from real data

- Classical herb-module statistics are computed from `osteoporosis_extraction_output_finalV6.xlsx`.
- The target quartet and all sub-combinations are tested explicitly (`core_module_significance.csv`); the complete four-herb co-occurrence is reported truthfully (support = 0), not overstated.
- Component identity is validated through PubChem PUG REST and ChEMBL molecule search.
- Component-target evidence is retrieved from ChEMBL activity records and mapped to gene symbols through ChEMBL target components, then tiered by assay type/potency (experimental) with a separate STRING-neighbour predicted layer.
- Osteoporosis target evidence is retrieved from Open Targets for `MONDO_0005298`.
- Network proximity uses STRING interactions queried from `string-db.org`, scored with a degree-preserving random reference (z-score, empirical p) and a random-equal-size-combination null.
- Reference marker localisation downloads PanglaoDB markers and computes target-marker overlap with a hypergeometric enrichment test.
- Expression localisation downloads the real GSE224152 processed matrix (aggregate; columns are cell barcodes, so cell-type-resolved localisation awaits an annotated matrix).
- Osteoclast dynamics downloads the real GSE246769 count matrix.
- Bone trait study discovery and gene-level enrichment query the GWAS Catalog REST API (`gwas_gene_enrichment.csv`).

## What is deliberately not faked

The following high-order analyses require large controlled inputs and are therefore marked as pending rather than simulated:

- SuSiE/FINEMAP fine-mapping;
- coloc/SuSiE-coloc;
- SMR/HEIDI;
- cis-eQTL/cis-pQTL Mendelian randomisation;
- LINCS Level 5 disease-signature reversal;
- scPerturb effect-size statistics;
- PrimeKG link prediction;
- structural docking and MM/GBSA.

The current high-order outputs are discovery and prioritisation tables that identify the public resources and candidate genes to carry forward.

## Advanced modules (`scripts/high_order_modules.py`)

These four modules follow the same contract — real computation wherever a public API allows it, structured `*_pending_steps.csv` records otherwise:

- **Module 1** computes real Open Targets `genetic_association` datatype scores, MyGene symbol→Ensembl mapping and eQTL Catalogue cis-eQTL presence, and re-grades targets so A-grade requires genuine human-genetics support. Fine-mapping, coloc, SMR/HEIDI and MR stay pending on full summary statistics / QTL tabix.
- **Module 2** computes real marker-niche assignment and GSE246769 module-expression scores; scVI/scANVI integration, cell2location/RCTD spatial deconvolution, UCell single-cell scoring, trajectory and CellChat/NicheNet communication stay pending on large single-cell/spatial matrices.
- **Module 3** builds a real osteoclast up/down signature from GSE246769 and queries Enrichr LINCS L1000 chemical and CRISPR-KO consensus libraries; weighted Level-5 CMap connectivity and scPerturb E-distance stay pending on the bulk signature files.
- **Module 4** builds a real herb→compound→target→pathway→disease knowledge graph with Reactome and Open Targets edges, runs shared-pathway meta-path link prediction, and records real UniProt/AlphaFold/PDB structural availability; PyKEEN/R-GCN embedding, GNINA/Vina docking and MD/MM-GBSA stay pending on binaries.

## Figure policy

PNG figures are generated by the pipeline at runtime and intentionally not committed, because the PR workflow does not support binary artifacts. Running the pipeline writes publication-ready PNGs to `results/figures/`.
